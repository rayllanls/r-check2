    ```python
    class CheckovTool(BaseTool):
        """Checkov IaC static analysis scanner.

        Checkov is a Python CLI tool installed via pip. resolve_binary() finds it
        in ~/.local/bin/checkov or system PATH -- no vendor/ copy needed.

        NOTE: severity is always null in OSS Checkov (no Prisma Cloud API key).
        All findings default to Severity.MEDIUM. The rule_id field carries the
        check_id (e.g., CKV_AWS_23) for user reference.

        Phase 7 PyInstaller: use --collect-all checkov OR invoke via
        sys.executable + ['-m', 'checkov'] instead of resolve_binary().
        """
        tool_name = "checkov"
    ```

    - run(): calls `[binary, "-d", str(project_path), "--output", "json", "--compact"]`
    - subprocess.run with capture_output=True, text=True, timeout=300 — NO check=True
    - Parse JSON, pass through _normalize_to_blocks(), iterate blocks calling _parse_failed_checks()
    - _normalize_to_blocks(raw): if list -> return raw; if dict with "check_type" -> return [raw]; if dict without "check_type" -> return [] (no-IaC summary)
    - _parse_failed_checks(block): iterate results.failed_checks, create Finding with:
      - title: "{check_id}: {check_name}"
      - severity: Severity.MEDIUM (hardcoded — OSS Checkov severity is always null)
      - category: FindingCategory.IAC
      - file_path: chk.get("file_path", "").lstrip("/")  <-- STRIP LEADING SLASH
      - line_number: file_line_range[0] if file_line_range else 0
      - snippet: resource field
      - description: "[{check_type}] {check_name}. See: {guideline}" (guideline only if non-empty)
      - tool: "checkov"
      - rule_id: check_id
