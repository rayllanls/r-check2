## Decisions Made

- **Severity hardcoded to MEDIUM:** OSS Checkov returns null severity for all checks — Prisma Cloud API key required for actual severity. Hardcoding MEDIUM is correct and documented in class docstring.
- **No vendor binary:** Checkov is a Python CLI installed via pip. `resolve_binary()` finds it in `~/.local/bin` or PATH. Phase 7 note added: use `--collect-all checkov` or `sys.executable + ['-m', 'checkov']` for PyInstaller.
- **_normalize_to_blocks dispatcher:** Abstracts 3 polymorphic output shapes cleanly before parsing — allows `run()` to iterate uniformly.
